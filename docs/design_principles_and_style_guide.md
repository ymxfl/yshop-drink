# 极客精酿小程序设计风格与设计原则指导文档

本文档总结了极客精酿小程序的整体设计风格、核心设计原则以及各页面的具体设计规范，旨在为后续功能的迭代开发提供坚实的视觉与交互基础。

---

## 一、 设计风格定位 (Design Theme)

极客精酿小程序整体采用 **“奢华暗金风格” (Premium Dark-Gold Theme)**。这种设计风格专为高端精酿品牌量身定制，通过深邃的背景色与高贵的金色细节，烘托出极客精酿的专业度、现代感与高品质。

*   **视觉感受**：奢华、沉浸式、专业、现代、高质感。
*   **适用人群**：追求生活品质的精酿啤酒爱好者、时尚都市青年、极客群体。

---

## 二、 核心视觉系统 (Color & Typography)

### 1. 调色板 (Color Palette)

为了打造极致的视觉沉浸感，并有效避免眼部疲劳，我们精心设计了以下暗金色彩系统：

| 色彩类型 | 十六进制 (HEX) | RGB 值 | 视觉用途与效果 |
| :--- | :--- | :--- | :--- |
| **主背景色 (Background)** | `#121212` | `rgb(18, 18, 18)` | 代替绝对纯黑（`#000`），作为全屏底色，提供开阔、高级的画布感。 |
| **卡片/容器背景 (Surface)** | `#1E1E1E` | `rgb(30, 30, 30)` | 用于导航卡片、状态栏、集杯卡与底部服务网格，使内容层级立体、清晰。 |
| **点缀金色 (Accent Gold)** | `#D4AF37` | `rgb(212, 175, 55)` | 标准拉丝金，用于图标描边、高亮边框、主要行动点（按钮）与品牌标示。 |
| **高亮淡黄 (Light Gold)** | `#F5D061` | `rgb(245, 208, 97)` | 柔和金色，用于重要文字标题、价格、高亮数值等，提升可读性。 |
| **主文本色 (Primary Text)** | `#FFFFFF` | `rgb(255, 255, 255)` | 高对比度纯白，用于主标题与重要文本内容。 |
| **次文本色 (Secondary Text)** | `#9E9E9E` | `rgb(158, 158, 158)` | 优雅灰色，用于副标题、描述性文本与次要说明。 |
| **禁用/暗色描边 (Border/Muted)** | `rgba(255, 255, 255, 0.05)` | - | 极薄白色半透明描边，用于微弱的层级划分与隐性边框。 |

### 2. 字体与排版 (Typography)

*   **数字字体**：价格、积分和余额等关键数字推荐使用现代等宽字体，保证对齐性与视觉冲击力。
*   **标题层级**：统一字号层级，避免乱用字号：
    *   超大促销字号：`50rpx` ~ `58rpx`
    *   主内容/商品标题：`30rpx` ~ `32rpx` (加粗)
    *   常态文本/列表项：`26rpx` ~ `28rpx`
    *   次要辅助文字：`20rpx` ~ `24rpx`

## 三、 设计原则 (Design Principles)

### 1. 拒绝纯白底色，杜绝视觉割裂 (No Leaking White)
*   **原则**：小程序内所有二级页面、弹窗、表单、提示框等均必须严格遵守暗色背景。
*   **实践**：严禁出现默认的微信白底，例如：
    *   结算页、购物车、兑换优惠券页的卡片和底部结算条必须是暗色（`#1E1E1E` 或 `#121212`）。
    *   输入框、按钮等组件的激活/非激活状态统一使用暗金搭配。

### 2. 移动端滚动适配，严控滚动条 (Scroll Control)
*   **原则**：关键的主控页面（如首页、点餐页、购物车、我的）应当严格进行整屏适配，避免双重滚动条或不必要的垂直溢出。
*   **实践**：
    *   点餐页使用 `flex` 布局或 `calc(100vh - header - footer)` 动态计算高度，使左右联动分类菜单完美贴合屏幕边缘，底部不留白，中间部分不溢出。
    *   首页使用精简的网格布局，删除低频次、冗余的卡片，保持页面清爽，避免页面无限向下滚动。

### 3. 微动效与触觉反馈 (Tactility & Micro-Animations)
*   **原则**：静态的设计是死板的，优秀的 UI 必须通过细微的动效与交互反馈让用户感知到小程序的生命力。
*   **实践**：
    *   **点击缩放**：对于可点击的卡片（如首页外卖自取卡片、底部网格），使用 `&:active { transform: scale(0.97); }` 提供瞬间的物理按压反馈。
    *   **平滑过渡**：边框颜色激活、按钮悬停等变化需加上 `transition: all 0.2s ease;`。
    *   **Tab 激活效果**：底部 Tab 选中后直接进行金色高亮（金色图标填充 + 金色文字），严禁展示突兀的蓝色聚焦框或系统默认边框。

### 4. 极致矢量图标系统 (Vector Icon Compatibility)
*   **原则**：图标背景必须是透明的，且能够在高分辨率下保持细腻。
*   **实践**：
    *   禁止使用带黑色或白色背景色的 JPEG/PNG 图标。
    *   微信小程序开发限制：**在微信小程序的视图层（WXML）中，由于渲染引擎限制，直接书写 HTML 原生 `<svg>` 标签在很多机型上无法正常渲染（显示为空白）**。
    *   **最佳兼容方案**：将所有精心设计的 SVG 代码转换为 Base64 Data URI，通过 Vue 的数据绑定，以 `<image :src="svgBase64Data" mode="aspectFit" />` 的形式引入。这既保证了小程序的完美跨平台兼容性，又保留了矢量图标的无损缩放和透明背景特性。

## 四、 核心页面组件化设计规范 (Page Component Standards)

### 1. 首页 (Home Page)
*   **结构划分**：
    *   **顶部 Swiper 轮播图**：长宽比固定，底部使用优雅的黑色线性渐变阴影（`linear-gradient`）过渡到背景，使文字标题层级分明。
    *   **快速入口卡片 (Takeout/Takein)**：左大右小黄金比例布局，强化核心点单业务入口。
    *   **个人资产统计栏 (Stats Bar)**：将会员积分、余额、可用优惠券横向排开，以简洁的一体化胶囊卡片展示，支持点击联动。
    *   **集杯卡组件 (Stamp Reward)**：核心留存裂变工具，采用八个啤酒杯的格子。用户消费时，将对应格子从灰色空杯（`beerGlassInactiveIcon`）平滑切换至满杯金色精酿（`beerGlassActiveIcon`），并伴有白色浮沫，增加集点乐趣。
    *   **底部服务网格**：缩减为 **卡券中心、积分商城、邀请有礼** 三大高频功能，单行并排，无底部边框，界面清爽无杂质。

### 2. 点餐页 (Menu/Ordering Page)
*   **结构划分**：
    *   **左侧分类菜单**：精简的暗灰背景（`#1E1E1E`），当前选中项高亮为金色，并带有一条金色的左侧垂直指示线。
    *   **右侧商品列表**：使用双向滚动联动，每个精酿商品以大图、双行标题、风味标签（如“浓郁麦香”、“皮尔森”）以及金色加号按钮呈现。
    *   **购物车悬浮窗 (Floating Cart)**：右下角独立悬浮或底部固定，购物车图标统一替换为透明底金色的极客定制矢量图标，高亮角标提醒。

### 3. 优惠券与卡券中心 (Coupons Page)
*   **卡片设计**：
    *   采用 **撕裂券边缘视觉效果**，使用虚线（`dashed`）或左耳圆缺设计，体现真实纸质优惠券的仪式感。
    *   兑换背景采用深黑奢华质感，彻底消除默认的白底，文字提示使用中高对比度的金色或次要灰色。
