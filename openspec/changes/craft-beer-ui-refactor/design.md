## Context

用户希望将现有的点餐小程序（当前样式为亮色、卡通用、多品类饮品风格）重构为专门销售“精酿啤酒及酒水”的专营零售小程序，并提供了两批共 10 张关键页面界面作为重构基准。

## Goals / Non-Goals

**Goals:**
- 将全部页面的 UI 升级为高保真暗黑色系（Premium Dark Mode），融合琥珀金、深炭灰。
- 重构全局 Sass 变量，保证 `uv-ui` 组件的色调与新主题一致。
- 优化核心流页面的视觉层级，突出商品的实物大图或精美插图。
- 确保所有 Vue 逻辑层（Vue Options/Composition API、Pinia Store、事件方法）及绑定的数据完全不受影响。
- 中文排版优化，对齐新设计的精酿小酒馆品牌定位。

**Non-Goals:**
- 不改变业务逻辑，不添加或删除已有的业务功能（如支付接口、卡券规则等）。
- 不重构后端 Java API。
- 本期不涉及微信小程序外的其他端（如 H5/App）的深度定制，但要保持 uni-app 跨端编译的正常运作。

## Decisions

### 1. 全局设计 Token 与变量配置
**决定**：在 `src/uni.scss` 中覆盖全局配色方案。
- 背景色：`$bg-color-dark: #121212`，卡片背景色：`$bg-color-card: #1E1E1E`
- 主色：`$color-primary: #D4AF37`（金色）与 `#F2A900`（琥珀橙）
- 文字色：主文字 `#FFFFFF`，副文字 `#9E9E9E`，激活金 `#D4AF37`

### 2. 页面重构规范与布局细节

#### A. 首页与店铺页
- **首页 (`src/pages/index/index.vue`)**：大 Swiper 轮播图配以“极客精酿 每日新鲜送达”暗色磨砂样式，半透明毛玻璃用户信息卡片，精细金色线性图标的堂食/外卖大按钮，以及啤酒杯集点卡进度栏。
- **店铺页 (`src/pages/components/pages/shop/shop.vue`)**：深灰色卡片，距离信息金色高亮，导航/呼叫操作使用精致的金色小按钮图标替代大色块按钮。

#### B. 点餐页与规格弹窗 (`src/pages/menu/menu.vue`)
- **点餐主体**：左侧分类列表底色设为深炭灰，选中分类字色改为金黄色并伴随竖条指示；右侧列表的精酿瓶装/听装图片添加圆角和阴影。
- **规格弹窗 (Specs Modal)**：大图预览，容量（330ml / 500ml）与温度（常温 / 冰镇 推荐）金线高亮边框，大面积金色“加入购物车”按钮。

#### C. 购物车与支付结算 (`src/pages/cart/cart.vue` & `src/pages/pay/pay.vue`)
- **购物车页**：商品大图展示（包含“冰镇”细微标徽），金黄色加减数控钮，底部应付总价高对比度金色去结算按钮。
- **支付页**：订单项目采用暗灰卡片，优惠券等详情对齐，支付方式栏（余额/微信支付）使用金色高亮选中项。

#### D. 个人中心 (`src/pages/mine/mine.vue`)
- 上方整合头像与金边，数据列（卡券/积分/余额）字号加大加粗；服务列表菜单全扁平化，引入统一的金色线性小图标（订单、地址、客服等）。

## Risks / Trade-offs

| 风险 | 缓解措施 |
|------|------|
| **微信小程序右上角胶囊遮挡** | 动态计算 `uni.getMenuButtonBoundingClientRect()` 并在页面顶部留出足够的 `padding-top`。 |
| **`uv-ui` 内置组件颜色覆盖失效** | 使用 Vue 3 的 `:deep()` (样式穿透) 强行修改 `uv-ui` 内部组件的背景及颜色。 |
| **首屏白屏或卡顿** | 确保重构引入的图片资源尺寸极小，背景图使用小图平铺或 base64/CDN，以符合小程序包限制。 |

## Migration Plan

1. 确认备份当前的代码分支。
2. 配置 `src/uni.scss` 设计变量。
3. 替换 `src/static/images/` 下的新图标及切图。
4. 依次修改首页、点餐页、购物车、订单、个人页的模板与样式。
5. 在真机（微信小程序开发者工具、iOS/Android 真机）中进行多分辨率适配。
